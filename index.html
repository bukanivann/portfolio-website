Tentang Saya

Halo! Selamat datang di portofolio saya.
Saya Ivan Saleh Guswanto. Ketertarikan saya pada dunia IT dan Engineering sudah tumbuh sejak masa SMK dan terus berkembang hingga saat ini sebagai Mahasiswa Teknik Telekomunikasi di Telkom University Jakarta.

Saya menggabungkan pola pikir analitis dengan eksekusi teknis. Pengalaman saya mencakup pengelolaan infrastruktur jaringan (Cisco, Fortinet, Mikrotik) hingga menjadi pemateri workshop arsitektur jaringan dan routing OSPF. Lebih dari itu, saya memiliki passion besar di bidang perangkat keras dan sistem embedded; mulai dari merakit robot pengontrol Bluetooth, mengembangkan IoT Ecosave untuk masyarakat, hingga merancang prototipe sistem Avionic untuk roket.
